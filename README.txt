親子のふりかえり PWA版

【最も簡単な公開方法（GitHub Pages）】
1. GitHubで新しい公開リポジトリ（例: oyako-reflection）を作る。
2. このZIPを解凍し、中の index.html / manifest.webmanifest / sw.js / icon-192.png / icon-512.png をリポジトリの直下にアップロードする。
3. Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save。
4. Pages に表示された https://...github.io/oyako-reflection/ をAndroidのChromeで開く。
5. Chromeメニュー（三点）→「アプリをインストール」または「ホーム画面に追加」。
6. 次回からホーム画面のアイコンを押して利用できる。初回に通信しておけば基本画面はオフラインでも開く。

【プライバシーの注意】
アプリのプログラムは公開サイトに置きますが、チェック記録やメモは端末のブラウザ内に保存し、サーバーには送信しません。
記録は機種変更時に自動で引き継がれません。CSVバックアップを使ってください。
現在のローカルHTML版の記録はPWAへ自動移行されません。
ホーム画面インストールにはHTTPS配信が必要です。ファイルを開いただけではインストールできません。
